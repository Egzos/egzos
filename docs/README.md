# docs/

`docs/` holds governance and build documentation for this repository.

## Layout

```
docs/
  build/    — build governance: the decisions log and build plan that drive the Phase 0.0 scaffold
```

## docs/build/

Build governance documents. See `docs/build/README.md` for the index.

## User documentation

User-facing documentation (install guide, CLI reference, MCP integration guide, `.xmb` format
reference) arrives with the v0.1 release. It will live under `docs/` once the walking skeleton
(Phase 0.1) lands and the contracts are frozen (Phase 0.3).
